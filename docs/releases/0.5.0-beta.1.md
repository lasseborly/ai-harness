# Aura 0.5.0-beta.1

- **Del** samler Azure Static Web Apps, Cloudflare Pages, GitHub Pages, komplai Run, Promte Apps og Vercel i samme forløb. Udbyderne vises alfabetisk med logo, kontokrav og tre valg ad gangen. Ingen udbyder er forvalgt.
- **Promte Apps**: Aura logger selv ind gennem Promte i browseren, så Promtes kommandolinjeværktøj ikke længere kræves. Du vælger en af dine apps eller opretter en ny. Aura viser, om versionen bygges, gennemgås, er blokeret eller er udgivet. Knappen **Åbn Promte** fører til arbejdsområdet.
- **Promte-apps i forhåndsvisningen** får rigtige modeller og data gennem Aura, når Promte-integrationen er slået til under Indstillinger. Første gang logger du ind og vælger **Opret appen … i Promte**. Adgangen bliver i Aura og når hverken appen eller brugerfladen. Del bruger samme app.
- **GitHub Pages og Cloudflare Pages** får opsætningsfiler i projektet. Aura viser filændringerne først; du gemmer og sender dem med Git. Udgivelsen starter efter dit valg gennem GitHub Actions. Cloudflares adgangstoken gemmes som en hemmelighed hos GitHub.
- **Azure Static Web Apps** guider gennem Microsoft-login, abonnement og valg af en eksisterende app i din egen Azure-opsætning.
- **Vercel** kan følge udgivelser fra et tilsluttet Git-repository og skelne mellem produktion og testversioner. Forbindelsen kan gemmes i projektets opsætning.
- En **fælles status ved Del** følger det åbne projekts udgivelse. Du kan se fremdrift og fejl og åbne appen eller udbyderens arbejdsområde. Gennemgang og kvittering følger samme opbygning på tværs af udbyderne.
- Browserlogin bruges, hvor udbyderen understøtter det. **komplai Run** beholder sit OAuth-login og vises på lige fod med de øvrige muligheder. Promte og komplai kræver konto og betalt aftale.
- **komplai er fjernet som AI-udbyder.** Tidligere gemte AI-forbindelser kan fjernes, men kan ikke længere sende opgaver eller hente modeller. Aura vælger ikke automatisk en anden AI. Run-adgang, projekter, samtaler og kladder bevares.
- Starten af Azure-, SWA- og Vercel-værktøjerne er rettet til deres officielle Windows-startfiler. Aura starter Node eller Python direkte, så adresser og filnavne med specialtegn ikke fortolkes som ekstra kommandoer.

## Opdatering

Opdateringsforløbet er uændret. Når automatisk søgning er slået til, søger Aura ved opstart og hver sjette time. Du vælger selv **Hent opdatering** og derefter **Genstart og opdatér**. Igangværende arbejde forhindrer genstart, og kladden gemmes inden installation.

Version 0.3.0-beta.1 og nyere har opdateringsfunktionen under Indstillinger. Ældre versioner kræver en manuel installation af en nyere version.

## Installation og afprøvning

Begge Mac-pakker er signerede med Developer ID og notariserede af Apple. Slutkontrollen bekræfter signaturer, vedhæftede Apple-billetter, distributionskontrol og samme app i DMG og ZIP. Windows-betaen er usigneret; Windows viser derfor en advarsel ved installation. Alle tre installationsfiler er kontrolleret mod den gennemgåede kildekode og har kontrolsummer til downloadkontrol.

360 relevante enhedsprøver består. De nye udgivelsesforløb er desuden afprøvet i Electron med faktiske projektfiler, tastaturbetjening, fejltilstande og visning ved 150 procent zoom. Udbydersvar og login er simuleret i disse prøver. Promte-login, appvalg og forhåndsvisning er afprøvet med lokale Promte-adaptere, herunder at forhåndsvisningen ikke kontakter Promte, før integrationen er slået til, og at en app først oprettes efter dit valg.

Rettelsen til Windows-startfiler er dækket af otte tests, inklusive faktiske lokale processer med specialtegn og standardinput. Det er ikke en Windows-platformsprøve.

På Apple Silicon er den pakkede app afprøvet med isolerede testdata, de medfølgende værktøjer og faktiske projektfiler. Opdateringen fra 0.4.0-beta.1 er kørt som en rigtig installation med den notariserede ZIP gennem den tidligere versions egen opdateringsfunktion. Projektfiler, forbindelse, krypteret testnøgle, designpakke og kladde er bevaret uden automatisk modelsendelse. Automatisk genstart efter opdateringen er ikke afprøvet.

Windows-installation, fysisk Intel-Mac, Promte i den pakkede app mod en rigtig Promte-server og de nye eksterne Promte-, GitHub Pages- og Cloudflare Pages-udgivelser er ikke afprøvet. Den aktuelle evidens og afgrænsning står i [teststatus](https://github.com/ai-alliancen-org/ai-harness/blob/main/docs/teststatus.md).
